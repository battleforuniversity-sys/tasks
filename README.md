# Приложение-ученик (PWA)

Файлы этой папки выкладываются на GitHub Pages. В Apps Script их загружать НЕ нужно (папка `tests` тоже не нужна на сайте).

Что выкладывать: `index.html`, `app.js`, `logic.js`, `plan.js`, `sw.js`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` и папку `img/` (рисунки к заданиям).

## Рисунки к заданиям
В листе Tasks добавьте десятую колонку `image` (заголовок в J1). В строке задания укажите имя файла, например `mat_gs1_os2_q03.jpg`, а сам файл положите в папку `img/` репозитория. Приложение покажет рисунок над вопросом и заранее скачает его для офлайна. В Telegram и на веб-страницах с планом рисунков нет.

## Один раз
1. GitHub → New repository (например `tasks`, Public) → Add file → Upload files → загрузите файлы из списка выше → Commit.
2. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save. Через минуту адрес будет вида `https://ИМЯ.github.io/tasks/`.
3. В Apps Script: скопируйте файлы сервера (Tasks.gs, Sync.gs, Api.gs, SeedTasks.gs, обновлённые Config.gs, Web.gs, Webhook.gs), сделайте новую версию развёртывания.
4. Запустите `setupApi`, затем `seedPresentPerfectTasks` (24 пробных задания), затем `checkApi`.
5. Сохраните адрес GitHub Pages в свойство скрипта `PWA_URL` и запустите `showApiSetup`: в логе появится ссылка для iPad.

## На iPad
1. Откройте ссылку из лога в Safari при включённом интернете. Приложение скачает задания.
2. «Поделиться» → «На экран Домой». Дальше запускайте только иконкой.
3. Если иконка откроется с экраном «Настройка», вставьте код настройки из лога (строка после «Код настройки»).
4. Проверка: включите авиарежим, решите несколько заданий, выключите авиарежим, откройте приложение — «Не отправлено» станет 0, строки появятся в листе Attempts.

## Обновление приложения
Заменили файлы на GitHub → при следующем открытии с интернетом iPad подхватит новую версию (в `sw.js` при крупных изменениях увеличьте номер в `CACHE`).

## Слова
Вкладка «Слова» и блок «📚 Слова — 10 минут» на экране «Сегодня»: 20 карточек в день, до 5 новых, сначала повторения. Карточки туда и обратно (турецкий ↔ русский/английский), с полным предложением. Ребёнок может добавить своё слово (работает без сети). Открытие «Слов в задании» считается сигналом «непонятно» — слово вернётся раньше. Данные идут в листы Vocab и VocabLog; при обновлении с v12 в `sw.js` стоит `tasks-shell-v15`.
